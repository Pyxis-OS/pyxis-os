An operating system where every resource is a URI served by a userspace provider, and programs hold only the capabilities they are granted.

In development since September 2026. Latest tagged release: {{ hugo.Data.source.latestRelease }}. {{ if not hugo.Data.project.isoPublished }}The {{ hugo.Data.project.isoVersion }} ISO is not published yet.{{ end }}

  • Its own kernel, Caelum, for x86-64 with SMP, written in C23.
  • Resources are addressed as URIs such as home://, system:// and https://; reading a web page is cat https://example.com.
  • Spaces: separate sessions with their own roots and grants.
  • Runs on a ThinkPad T14 (AMD), an IdeaPad Slim 5 (Intel) and QEMU.
  • Native Neovim with clangd, Clang, a package manager, Doom and Quake.
