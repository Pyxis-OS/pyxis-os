Expressions entered in the retained debugger sessions. GDB logging captured
results but omitted entered commands; $N labels below identify those results.
This is a record of inspection, not an executable validation script.

context-gdb.txt (earlier Bluetooth-only consumer variant)
  set $bt = interrupt_probe_device
  $1: p $bt->interrupt->sequence
  $2: p $bt->interrupt->queue_count
  $3: p $bt->interrupt->enqueue
  $4: p $bt->interrupt->cycle
  $5: p $bt->interrupt->result
  $6: p $bt->interrupt->receive[0]
  $7: p $bt->interrupt->receive[1]
  $8: p $bt->controller->context_bytes
  $9: p $bt->controller->interrupts
  Context words:
    x/5wx $bt->output.address + $bt->interrupt->dci * $bt->controller->context_bytes

  $2: p interrupt_probe_device->interrupt->queue_count
  $3: p interrupt_probe_device->interrupt->result

  $7: p $bt->interrupt->cycle
  $8: p $bt->controller->running

  $11: p $bt->controller->bulk[0].in.dci
  $12: p $bt->controller->bulk[0].state
  $13: p $bt->controller->bulk[0].result
  $14: p $bt->controller->bulk[0].actual
  Queued event bytes:
    x/15bx $bt->interrupt->queue[$bt->interrupt->queue_head].bytes

progress-gdb.txt
  Startup breakpoint:
    hbreak usb_host_control_wait
    condition 1 interrupt_probe_device != 0 && interrupt_probe_device->interrupt->sequence == 271
  At that stop:
    disable 1
    hbreak drain_events
    condition 2 interrupt_probe_device->interrupt->sequence == 271
    continue
  At drain_events:
    bt
    $1: p interrupt_probe_device->interrupt->sequence
    $2: p interrupt_probe_device->interrupt->enqueue
    finish
    $3: return value of drain_events
    $4: p interrupt_probe_device->interrupt->sequence
    $5: p interrupt_probe_device->interrupt->enqueue
    $6: p interrupt_probe_device->interrupt->queue_count

removal-gdb.txt
  set $bt = interrupt_probe_device
  $1: p $bt->controller->running
  $2: p $bt->controller->failed
  $3: p $bt->controller->interrupt_ready
  $4: p $bt->interrupt->result
  $5: p $bt->interrupt->receive[0]
  $6: p $bt->interrupt->receive[1]
  $7: p/x $bt->interrupt->ring.physical
  $8: p/x $bt->controller->interrupt_dma.physical
  $9: p $bt->interrupt->queue_count
